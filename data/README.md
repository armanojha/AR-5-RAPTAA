# Data directory

This directory contains **different data classes**. Do not treat them all as independent ground truth.

- `sample_*` files are small synthetic fixtures for deterministic tests.
- `real_cache/` contains cached OSM alignments, public satellite/context metadata and image chips for three corridor case studies. Large GeoTIFF and NumPy raster windows are excluded from Git and must be ingested before rebuilding the complete pipeline.
- `real_*` files are case-study inputs and derived records. Some project figures are configured manually; some reporting trajectories and labels are generated by the demo pipeline. Their `real` classification must not be read as independent validation of every field.
- `evidence_chips/` and `geotiffs/` contain demonstration assets used by examples and tests.

For exact sources, processing and validation limits, read [Data and validation](../docs/DATA_AND_VALIDATION.md). New real records must include source URL, source date and provenance; classify records combining official and generated values as `mixed` and identify generated fields. Do not commit credentials, restricted imagery or data whose licence forbids redistribution.
